# 営業ボイス議事録

商談の音声をその場で録音するだけで、AI（Google Gemini）が自動で文字起こし・要約してくれるiPhone対応Webアプリです。

- 録音 → 送信すると、AIが「担当者名・商談相手・要約（箇条書き）・全文文字起こし」を自動生成
- 訪問日を記録できる簡易カレンダー付き
- データはこの端末（iPhoneのSafari）の中だけに保存されます（サーバーには保存されません）
- 切削工具・日進工具（NS TOOL）関連の専門用語をAIがあらかじめ理解した状態で解析します

このアプリを実際にiPhoneで使えるようにするには、次の3ステップが必要です。

1. **Gemini APIキーを取得する**（無料）
2. **このコードをGitHubに置く**
3. **Renderというサービスにデプロイする**（無料）

順番に、初めての方でも迷わないように説明します。難しい専門知識は不要です。上から順番にコピー＆ペーストしていけば大丈夫です。

---

## ステップ1：Gemini APIキーを取得する（無料）

このアプリの「AIが音声を聞き取る」部分は、Googleの Gemini というAIを使っています。利用するには「APIキー」という、そのAIを使うためのパスワードのようなものが必要です。無料で取得できます。

1. ブラウザで **https://aistudio.google.com/apikey** を開く
2. お持ちのGoogleアカウント（普段使っているGmailのアカウントでOK）でログインする
3. 「**Create API key**」または「**APIキーを作成**」というボタンをクリックする
4. 表示された文字列（`AIza`から始まる長い文字列）が、あなたのAPIキーです。**この画面を閉じる前に、どこかにコピーしておいてください**（メモ帳など）

> ⚠️ このAPIキーは人に見せたり、SNSやチャットにそのまま貼り付けたりしないでください。あなたのAI利用料の請求に関わる、大事な情報です。
>
> 💡 無料枠の範囲であれば料金は発生しませんが、心配な場合はGoogle AI Studioの画面で利用状況を確認できます。

これでステップ1は完了です。取得したAPIキーは、ステップ3で使います。

---

## ステップ2：このコードをGitHubに置く

デプロイ（インターネット上でアプリを動かすこと）をするには、コードをGitHubという場所に置いておく必要があります。gitコマンドなどは使わず、ブラウザの操作だけで完結します。

1. **https://github.com** にアクセスし、アカウントを持っていなければ「Sign up」で無料登録する（メールアドレスがあればOK）
2. ログインしたら、右上の「＋」ボタン→「**New repository**」をクリック
3. 「Repository name」に好きな名前を入力（例：`sales-voice-memo`）
4. 公開・非公開はどちらでもOKですが、非公開にしたい場合は「**Private**」を選ぶ
5. そのまま「**Create repository**」をクリック
6. 作成された画面の中に「**uploading an existing file**」というリンクがあるのでクリック
7. お渡ししたこのフォルダの中身（`server.js` や `package.json`、`public` フォルダなど**全部**）を、その画面にドラッグ＆ドロップする
   - ※ `.env` というファイルがもし存在しても、それだけはアップロードしないでください（APIキーが含まれるファイルです。今回お渡しした状態には含まれていないので心配いりません）
8. 画面下の「**Commit changes**」をクリックすればアップロード完了です

これでコードがGitHub上に置かれました。

---

## ステップ3：Renderにデプロイする（無料）

Render（レンダー）は、クレジットカード登録なしで無料利用を始められるサーバーサービスです。GitHubと連携すると、コードを置くだけで自動的にインターネット上にアプリを公開してくれます。

1. **https://render.com** にアクセスし、「**Get Started**」からアカウントを作成する（「**Sign up with GitHub**」を選ぶと、ステップ2で使ったGitHubアカウントと連携できて簡単です）
2. ログイン後、ダッシュボードで「**New +**」→「**Web Service**」を選ぶ
3. GitHubのリポジトリ一覧が表示されるので、ステップ2で作った `sales-voice-memo`（あなたが付けた名前）を選んで「**Connect**」
4. 設定画面が出るので、以下のように入力（多くは自動で入力されます）
   - **Name**：好きな名前でOK（例：`sales-voice-memo`）※これがURLの一部になります
   - **Region**：どこでも良いですが、`Singapore` を選ぶと日本から比較的速いです
   - **Build Command**：`npm install`
   - **Start Command**：`npm start`
   - **Instance Type**：「**Free**」を選ぶ
5. 少し下にスクロールすると「**Environment Variables**」（環境変数）という項目があります。ここに、ステップ1で取得したAPIキーを設定します
   - 「**Add Environment Variable**」をクリック
   - Key：`GEMINI_API_KEY`
   - Value：ステップ1でコピーしたAPIキー（`AIza...`から始まる文字列）を貼り付け
6. 一番下の「**Create Web Service**」（または「Deploy Web Service」）をクリック

これで自動的にビルド・デプロイが始まります。画面にログがどんどん流れますが、数分待つと「**Live**」という緑色の表示に変わります。そうなれば完了です。

画面上部に、`https://sales-voice-memo-xxxx.onrender.com` のようなURLが表示されているので、それがあなたのアプリのURLです。

> ⏱️ **無料プランの注意点**：15分間アクセスがないと、サーバーが自動的にスリープ（お休み）します。スリープ中に久しぶりにアクセスすると、最初の1回だけ画面が表示されるまでに30〜50秒ほどかかります（2回目以降は普通の速さに戻ります）。これは無料プランの仕様なので、故障ではありません。

---

## ステップ4：iPhoneで開く

1. iPhoneの**Safari**（標準のブラウザアプリ）で、ステップ3で表示されたURL（`https://〜.onrender.com`）を開く
2. 録音の許可を聞かれたら「**許可**」をタップ
3. マイクのボタンをタップして商談内容を話し、終わったら停止ボタンをタップすると、AIが自動で文字起こし・要約してくれます

### ホーム画面に追加すると、アプリのように使えます（任意）

1. SafariでURLを開いた状態で、下部（または上部）の「共有」ボタン（四角から矢印が出ているアイコン）をタップ
2. 「**ホーム画面に追加**」を選ぶ
3. ホーム画面にアイコンが追加され、タップするとアプリのようにすぐ開けるようになります

## データはどこに保存される？

商談の記録（文字起こし・要約・カレンダーの予定）は、**すべてiPhoneのSafari内（localStorage）にのみ保存**され、サーバーには一切保存されません。そのため、

- Safariの「履歴とWebサイトデータを消去」を行うと、記録も消えてしまいます
- 別の端末やブラウザから同じ記録を見ることはできません（この端末専用の記録です）
- サーバー（Render）を再起動しても、記録が消える心配はありません（そもそもサーバー側には何もないため）

将来的に「複数端末で共有したい」「バックアップを取りたい」などの要望が出てきたら、サーバー側にデータベースを追加する形で拡張できます。

## 困ったときは

- **「AI解析に失敗しました」と出る**：Renderのダッシュボードで `GEMINI_API_KEY` が正しく設定されているか確認してください（ステップ3の5）。また、スマホの電波状況が悪いと失敗しやすいので、Wi-Fiや電波の良い場所で試してください。
- **画面がなかなか表示されない**：無料プランのスリープからの復帰中の可能性があります。30〜50秒ほど待ってから再読み込みしてください。
- **マイクの許可を聞かれない/使えない**：iPhoneの「設定」→「Safari」→「マイク」で、このサイトのマイクアクセスが許可されているか確認してください。

## （参考）ローカルで動作確認したい場合

開発者向けの補足です。自分のパソコンで動かして確認したい場合は、以下のコマンドを使います。

```bash
npm install
cp .env.example .env
# .env を開いて GEMINI_API_KEY=あなたのAPIキー を記入
npm start
```

その後、ブラウザで `http://localhost:3000` を開くと確認できます（ただし録音機能はブラウザによって挙動が異なるため、実機での最終確認はiPhoneのSafariで行ってください）。
